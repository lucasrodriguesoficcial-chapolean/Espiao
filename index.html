    Meta de teste: 7 dias

    Produza 5 vídeos curtos, 2 posts em carrossel ou stories, 1 comparação útil e acompanhe o que foi publicado. Dê continuidade apenas aos produtos que gerarem interesse e cliques qualificados.

    Automação opcional

    Atualizar toda segunda-feira

    O pacote inclui uma ação agendada do GitHub. Ela consulta a API oficial, recalcula a seleção e atualiza o site hospedado.

    1
    Crie um repositório no GitHub

    Envie os arquivos da pasta do projeto e habilite GitHub Pages na branch main, diretório raiz.

    2
    Ative sua Open API de afiliados

    Obtenha o App ID e o Secret na área autorizada da Shopee. Não coloque credenciais nesta página.

    3
    Salve credenciais nos GitHub Secrets

    Em Settings → Secrets and variables → Actions, crie SHOPEE_APP_ID e SHOPEE_APP_SECRET.

    4
    Habilite o agendamento

    O arquivo .github/workflows/atualizar-radar.yml executa às segundas-feiras, 09h de Brasília (sujeito a atrasos do GitHub). Execute manualmente uma vez para testar.

    🔒 Segurança e limites

    O segredo só é lido na execução do GitHub, nunca no navegador. A lista vem dos produtos consultados pela API, não de toda a Shopee. A automação depende das permissões da sua conta, do GitHub Actions e das respostas da API.

    Seu acompanhamento

    Links de afiliado

    No modo amostra, os botões abrem a busca da Shopee. Você pode salvar seu próprio link para cada produto; ele fica guardado neste navegador.

    Como usar seu link corretamente

    Abra o portal Shopee Afiliados, gere o seu link rastreável para o anúncio exato e, no radar, clique em “Meu link”. Assim você evita divulgar links de outros afiliados.

    Fontes e transparência

    Recarregar a página só lê os dados já publicados; não inicia uma consulta à Shopee. Para atualizar antes da segunda-feira, use “Run workflow” no GitHub Actions.

    Radar Afiliado • Projeto independente, sem vínculo com a Shopee. Os dados públicos e as comissões podem mudar. Confirme preço, estoque, regras, comissão e condições do anúncio antes de divulgar. Fonte oficial sobre listas de produtos.
